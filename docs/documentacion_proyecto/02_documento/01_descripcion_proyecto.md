# Descripción del proyecto

El proyecto es una aplicación móvil Android orientada a la gestión y comercialización de proyectos inmobiliarios. Su propósito es reunir en una sola plataforma las tareas que normalmente se realizan por medios separados, como revisar información de inmuebles, conversar con un asesor, coordinar una visita, registrar una separación y controlar las actividades administrativas de una inmobiliaria.

La aplicación atiende a cuatro tipos de usuario. El cliente puede registrarse, iniciar sesión, explorar proyectos, consultar sus características, ver su ubicación, escanear un código QR, contactar a un asesor, reservar una cita y revisar su actividad. El asesor cuenta con una agenda en tiempo real, chat con clientes, historial de visitas y gestión de separaciones. El administrador mantiene los proyectos de su empresa, sus imágenes, tipologías y amenidades, además de asignar asesores, revisar solicitudes, recibir notificaciones y consultar reportes. Finalmente, el superadministrador administra usuarios, invitaciones para nuevos administradores, solicitudes globales, reportes y registros del sistema.

El problema que busca resolver es la dispersión de información durante el proceso de atención inmobiliaria. Sin una herramienta centralizada, un cliente puede recibir datos distintos por teléfono, mensajería y visitas presenciales, mientras que los asesores y administradores tienen dificultad para conocer qué proyecto, cita o separación corresponde a cada persona. En esta aplicación, las entidades principales se relacionan mediante identificadores guardados en Firestore. Por ejemplo, una cita contiene el cliente, el asesor y el proyecto; una asignación vincula un proyecto con un asesor; y una conversación conserva los participantes y, cuando corresponde, el proyecto sobre el cual se está conversando.

La aplicación fue desarrollada de forma nativa para Android con Java, Activities, layouts XML, RecyclerView y View Binding. Firebase Authentication se encarga del acceso con correo y contraseña o cuenta de Google. Cloud Firestore almacena perfiles, empresas, proyectos, asignaciones, citas, conversaciones, mensajes, separaciones, notificaciones y reportes. Supabase se utiliza de forma complementaria para almacenar imágenes. La aplicación obtiene un token de Firebase y lo envía a una Edge Function de Supabase; la función valida la identidad y recién entonces sube la imagen al bucket configurado.

También se integraron bibliotecas para funciones específicas. Glide carga imágenes remotas, OkHttp se comunica con las Edge Functions, ZXing genera y escanea códigos QR, y Google Maps con Places permite explorar y seleccionar ubicaciones. Para las agendas se utiliza una vista de calendario externa y los cambios de Firestore se reciben mediante listeners en tiempo real.

El valor agregado del proyecto está en conectar el recorrido completo del cliente con el trabajo interno de la inmobiliaria. El QR de un proyecto puede abrir directamente su detalle; desde ese detalle se puede iniciar un chat o una cita; la cita aparece en la agenda del asesor asignado; y una separación puede generar una notificación para el administrador. Aunque todavía existen riesgos de seguridad y algunas pantallas conservan almacenamiento local o comportamiento demostrativo, la base implementada permite representar un flujo inmobiliario completo dentro de una sola aplicación móvil.
