## Nota metodológica

Las fuentes oficiales sirvieron para validar el funcionamiento esperado de las tecnologías y calcular costos. La descripción de lo que realmente está implementado se obtuvo del repositorio, no de estas páginas. Por ejemplo, aunque Firebase ofrece FCM y Cloud Functions, no se documentaron como funciones del sistema porque no aparecen en el código.
